## Web Development Hardware Requirements

**RAM:** 16GB for full-stack developers running local DB + API server + frontend dev server simultaneously. 8GB is workable for frontend-only work (React, Vue, HTML/CSS).

**SSD speed:** npm install with 1,000+ packages, Docker image pulls, Next.js build times — all IO-bound. Gen 4 NVMe SSDs can be 3–4× faster than Gen 3 for these operations.

**Display:** At least FHD (1920×1080). WQHD (2560×1440) or Retina is better for reading dense code without eye strain. 14–15 inches for desk work; 13 inches if highly portable.

**Ports:** USB-C/Thunderbolt for external monitors and docking. At least one USB-A for legacy devices. HDMI is convenient for connecting to projectors/monitors without adapters.

## 1. MacBook Air M2 — Best Overall

**Price:** ₹94,900 (8GB) / ₹1,19,900 (16GB, 512GB)

The MacBook Air M2 is what most professional web developers at Bangalore, Hyderabad, and Pune tech companies carry. Why:

**npm/pnpm/yarn install speeds:** Apple Silicon's memory bandwidth and SSD controller make Node.js package installation 2–3× faster than Intel equivalents. A 15-second npm install on M2 takes 45 seconds on an i5 laptop.

**Docker:** Docker Desktop on Apple Silicon (arm64) works natively. Containers start in 2–3 seconds vs 10–20 seconds on Windows.

**Browser DevTools:** Opening 10+ browser tabs + DevTools + code editor simultaneously works smoothly on M2 with 8GB. On 8GB Windows laptops, this combination causes slowdowns.

**Terminal:** macOS zsh + iTerm2 + Homebrew is the best-in-class developer terminal setup. SSH, git, and shell scripting all work natively.
