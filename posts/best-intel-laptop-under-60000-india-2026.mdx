## Intel 12th vs 13th Gen Under ₹60,000

**12th Generation (Alder Lake, 2021):** Core i5-1235U, Core i7-1255U. Still available new. Solid performance but 13th gen is a meaningful upgrade — 20–25% better multi-core performance.

**13th Generation (Raptor Lake, 2022):** Core i5-1335U, Core i7-1355U. Better efficiency cores (E-cores) handle background tasks; P-cores handle demanding work. Available at similar prices as 12th gen.

**Intel Core Ultra (Meteor Lake, 2024):** Core Ultra 5 125U, Core Ultra 7 155U. Latest architecture, integrated neural processor (NPU). Available in higher-end laptops above ₹70,000 but occasionally appears in promotions under ₹60,000.

At ₹60,000, target 13th gen Core i5-1335U minimum. Core i7-1355U is worth paying for if you find it in budget.

## Why Thunderbolt 4 Matters

If you plan to:
- Use an external 4K monitor via USB-C
- Expand to a Thunderbolt dock with multiple ports
- Connect an eGPU enclosure for gaming
- Transfer large files fast (40 Gbps vs USB 3.2's 10 Gbps)

...then Intel with Thunderbolt 4 has a clear advantage. AMD laptops under ₹60,000 typically offer USB4 (similar bandwidth) but lack Thunderbolt certification and accessory ecosystem.

**Recommendation:** IdeaPad Slim 5i for Thunderbolt 4 + balanced performance. HP Pavilion Plus 14 if you need sustained heavy performance and can sacrifice some battery life. Dell Inspiron 14 for reliability and simplicity.
