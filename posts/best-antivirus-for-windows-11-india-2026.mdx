## 1. Windows Defender (Built-in, Free) — For Most Users

Windows 11 automatically enables Defender when no third-party antivirus is installed. Keep it enabled. Don't disable it for "performance" reasons — the impact is negligible.

Recommended settings:
- Enable Real-time protection (on by default)
- Enable Cloud-delivered protection (sends suspicious files to Microsoft for analysis)
- Enable Automatic sample submission (helps improve detection)
- Schedule weekly full scans (Windows Security → Virus protection → Scan options)

Windows Security app also includes Firewall & network protection, App & browser control (SmartScreen), and Device security — a complete security suite at no cost.
