## What Matters for Coding Laptops

**RAM (Most Important):** 16GB minimum. Running VS Code or IntelliJ + a browser + Docker containers simultaneously requires 8–12GB. 16GB provides headroom for multiple projects. 8GB is insufficient for modern development workflows.

**Processor:** AMD Ryzen 5 processors (7530U, 5625U, 5500U) offer excellent multi-core performance at under ₹40,000 — faster compilation than comparable Intel Core i5 configurations at this price.

**SSD:** 512GB NVMe minimum. Code repositories, node_modules, virtual environments, and build artifacts accumulate quickly. HDDs and eMMC storage cause IDE lag — only buy laptops with NVMe SSD.

**Display:** FHD (1920×1080) is adequate for coding. IPS preferred for wider viewing angles. High-refresh-rate displays (120Hz+) add cost without productivity benefit for coding.

**Battery:** Important if coding away from power outlets. Ryzen 7000 series (7530U) offers better battery efficiency than older Ryzen 5000 series.
