## Honest Expectations at Under ₹30,000

**What works fine:**
- Python scripting (Django, Flask, basic data science)
- HTML/CSS/JavaScript web development
- C and C++ programming (college assignments)
- Java basic programs (not large Android projects)
- Competitive programming (single algorithm test)

**What struggles:**
- Android Studio with emulators (needs 16GB and faster CPU)
- Large Java projects (Spring Boot, Maven multi-module)
- Docker containers
- Running multiple development servers simultaneously

**Not possible:**
- Local machine learning training (needs GPU or faster CPU)
- Game development (Unity, Unreal)
