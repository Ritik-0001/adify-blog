## What Cybersecurity Work Demands

**RAM:** 32GB is ideal if you run multiple VMs (Kali + target machine + Windows Server). 16GB is the minimum comfortable setup for 2 simultaneous VMs. 8GB will throttle you.

**CPU cores:** VM hypervisors (VirtualBox, VMware) benefit from more cores. 6+ physical cores is the target. Ryzen 5/7 and Core i5/i7 H-series are both fine.

**Virtualization support:** All modern CPUs support Intel VT-x or AMD-V (required for VMs). Verify it's enabled in BIOS before buying.

**Linux compatibility:** Not all laptops run Linux well. ThinkPads have the best Linux driver support of any Windows laptop. ASUS ROG also has good Linux support. Some HP and Dell models have Wi-Fi and touchpad driver issues on Linux.

**Network card:** Internal Wi-Fi cards don't support monitor mode (required for Wi-Fi security testing). You'll need a USB Wi-Fi adapter (Alfa AWUS036ACS, ₹2,500–₹4,000) regardless of laptop.
