## Python Use Case Breakdown

### Web Development (Django, Flask, FastAPI)
Requirements: 8–16GB RAM, SSD, decent CPU. The Ryzen 5 VivoBook handles Django development smoothly — local development servers and SQLite/PostgreSQL development databases use minimal resources.

### Data Science (Jupyter, pandas, NumPy, scikit-learn)
Requirements: 16GB RAM minimum. Pandas operations on datasets above 1GB fill RAM quickly — 16GB prevents constant swapping. Ryzen 7's 8 cores parallelize NumPy operations faster.

### Machine Learning (TensorFlow, PyTorch — CPU training)
Requirements: 16GB RAM, 8+ CPU cores. For ML with local CPU training (no GPU), Ryzen 7 7730U at ₹45,000–₄₉,000 is the best available under ₹50,000. GPU training at this price point isn't available — requires discrete GPU laptops starting at ₹65,000+ (ASUS TUF Gaming with RTX 4060).

### Competitive Programming (Codeforces, HackerRank, LeetCode)
Requirements: Any modern laptop. Python's slower execution in competitive programming (relative to C++) means faster hardware helps less than algorithm choice.
